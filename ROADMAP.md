# Roadmap

Bri Command Hub is a deliberately small, local-first Android workspace. This roadmap describes possible next steps, not promises or automatic device changes.

## Now

- [x] Private workspace for drafts, generated assets, quarantine and audit records
- [x] Fixed local actions for drafts, generated-file listing, quarantine and restore
- [x] First-build Status card generator for local review
- [x] Optional read-only root-status diagnostic

## Next

- [ ] Improve the draft templates for practical Android and Linux guides
- [ ] Add a reviewed export-to-Pictures action for generated cards
- [ ] Add clear local preview guidance for generated media
- [ ] Expand safety tests for file-handling edge cases
- [ ] Document a manual WhatsApp Status handoff: prepare, review, select audience, send

## Later

- [ ] Add optional local content-pack templates for NexVanta guides
- [ ] Add a simple Android companion interface that only exposes the same fixed actions
- [ ] Publish a reproducible test checklist for Samsung Android and Termux

## Boundaries

The project will keep explicit human approval for outgoing messages, publishing, app changes and root actions. It will not add arbitrary-shell execution, stealth monitoring, WhatsApp automation or security-bypass features.
